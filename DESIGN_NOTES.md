# Aurora UI refresh

A visual-only restyle of the existing Expo / React Native attendance app.

- Unified midnight navy backgrounds, electric indigo CTAs and mint/aqua highlights.
- Added decorative ambient SVG lighting behind the app (pointer events disabled).
- Refreshed the home dashboard branding, hero, scan card, and quick-access tiles.
- Harmonized shared buttons and floating tab navigation across student, teacher and admin views.
- Preserved all original routes, authentication/authorization logic, QR-scanning behavior, attendance operations, Supabase integration and dependencies.

Run `npm install` then `npx expo start` in the project folder. Provide existing Supabase environment variables as before.
